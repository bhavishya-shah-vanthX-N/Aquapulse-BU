## AquaPulse BU — Campus Water Footprint & SDG 6 Action Hub

A lightweight, mobile-first web application built for the **BU100 SDG Action Lab** at Bennett University to address **SDG 6 (Clean Water and Sanitation — Target 6.4: Water-Use Efficiency)**.

## Empirical Foundation
Grounded in a baseline student survey ($N=100$) at Bennett University:
- **60%** of respondents identified water scarcity as a top ecological concern.
- **68%** recognized India's **Jal Jeevan Mission**, yet **72%** reported incomplete campus sustainability engagement.

## Architecture
- `index.html`: Two-screen interactive assessment and 7-day pledge interface.
- `style.css`: Responsive UI styling using clean CSS variables.
- `script.js`: Water-use efficiency calculation logic and Google Form pilot telemetry hook.
